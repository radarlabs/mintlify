<Info>
  The AWS S3 export is available on the [Enterprise plan](https://radar.com/pricing) and must be enabled for your project. Contact your Radar account team.
</Info>

Radar delivers your project's events and locations to your S3 bucket as Parquet files. This export is unrelated to [geofence sync](#sync-geofences-from-a-csv-in-s3), where Radar reads a geofence CSV from your bucket.

## Prerequisites

- The AWS values for the bucket policy, from your Radar account team. The dashboard has no control for this export.
- Permission in AWS to create an S3 bucket and edit its bucket policy.

## Configuration

An Amazon Data Firehose delivery stream in Radar's AWS account writes new events and locations to your bucket through cross-account delivery, starting when Radar enables the export.

### Create a bucket

Create an S3 bucket, for example `s3://com.example.bucket/`, and send the bucket name to your Radar account team. Radar delivers event files under this path, where `$PROJECT` is your Radar project ID:

```text
s3://com.example.bucket/radar/events/project=$PROJECT/dt=YYYY-MM-DD/X.parquet.snappy
```

### Create an AWS Cross-Account IAM policy

1. Ask your Radar account team for the `accountA-id` and `iam-role-name` values for your export.
2. Follow step 2 of AWS's [cross-account delivery to an Amazon S3 destination](https://docs.aws.amazon.com/firehose/latest/dev/controlling-access.html#cross-account-delivery-s3) instructions to attach a bucket policy that grants that role access. Radar performs steps 1 and 3.
3. Tell your account team that the policy is in place.

## Schema

Files are Snappy-compressed Parquet with Hive-style `project=` and `dt=` partitions, which Amazon Athena, Apache Spark, and your warehouse's S3 ingestion can read. Column names are Radar's field names, lowercased. Join to your own user tables on `userexternalid`. Metadata columns hold stringified JSON.

## Test the integration

After your account team confirms that delivery is on, generate an event in the project, wait at least 10 minutes, then list the day's folder:

```bash
aws s3 ls "s3://com.example.bucket/radar/events/project=YOUR_PROJECT_ID/dt=2026-06-12/"
```

The command lists one or more `.parquet.snappy` objects. In Amazon Athena, with a table over the `radar/events/` prefix and its partitions loaded, this query returns the event:

```sql
SELECT _id, type, userexternalid, geofenceexternalid, createdat
FROM radar_events
WHERE dt = '2026-06-12'
  AND live = false
ORDER BY createdat DESC
LIMIT 10;
```

Delivery errors aren't visible in your AWS account or in the integration logs. If no files arrive, check the bucket name, the `accountA-id` and `iam-role-name` in the bucket policy, and any bucket setting that rejects cross-account writes, such as a required customer-managed KMS key. Then contact your account team.

## Limitations

- The export is batched: the stream flushes a file after 10 minutes or 128 MB of data, whichever comes first. To react to an event as it happens, use [webhooks](/integrations/webhooks).
- `dt` is the delivery day, not the day the event occurred. Use `createdat`, `actualcreatedat`, or `updatedat` for time-based analysis.
- The export has no [filters](/integrations/integrations#filters). Filter on columns such as `type`, `live`, or `geofencetag` when you query.
- Deduplicate on `_id` (events) and `locationid` (locations) if you need one row per record.
- Radar doesn't provide a warehouse connector.

## Sync geofences from a CSV in S3

Geofence sync imports geofences into Radar: you put a geofence CSV in a private S3 bucket and Radar reads it on a schedule. It doesn't use the export. Configure it on the [Integrations](https://dashboard.radar.com/integrations) page, in the **Geofence sync** section: select **AWS S3** for **Protocol**, then enter the bucket **Region**, the **Bucket** name, the **Live CSV object key** and **Test CSV object key**, and the **Access key ID** and **Secret access key** of an IAM user that has `GetObject` permission for those objects.

For the CSV format and the sync schedule, see [Detect geofence events and place visits](/geofencing/geofences-and-places).
