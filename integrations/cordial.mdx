<Info>
  The Cordial integration is available on the [Enterprise plan](https://radar.com/pricing).
</Info>

Radar sends contact activities and updated contact attributes to [Cordial](https://cordial.com) each time it generates a location event.

## Prerequisites

- A Radar project on the Enterprise plan that is [generating events](/geofencing/geofences-and-places).
- A Cordial account where you can create API keys.
- The Cordial contact ID in your app, or a secondary key such as `emailHash` that the Cordial team creates.

## Configuration

<Steps>
  <Step title="Create a Cordial API key">
    In Cordial, open the **API Keys** page and create an API key with **Contact Activities** permissions.
  </Step>
  <Step title="Enter the settings in Radar">
    On the [Integrations](https://dashboard.radar.com/integrations) page, select **Yes** for **Enabled** in the **Cordial** section, enter these values, and click **Save**.

    | Field | Value |
    | --- | --- |
    | **Async API endpoint** | Required. For example `https://integrations-ingest-svc.usw2.cordial.com`, without a trailing path. |
    | **Live API key** | For Live events. |
    | **Test API key** | For Test events. |
    | **Cordial secondary key** | The name of the secondary key. Leave empty if you use only the Cordial contact ID. |
  </Step>
</Steps>

## Identity mapping

Radar doesn't use the Radar `userId`. It uses the first of these values that is set, or skips the event with `Identifier missing.`

| Radar value | Sent to Cordial as |
| --- | --- |
| `metadata.cordialId` | The `cID` contact identifier |
| `metadata["cordial:{secondaryKey}"]`, where `{secondaryKey}` is the **Cordial secondary key** setting | The secondary key identifier |

<CodeGroup>

```swift Swift
import RadarSDK

Radar.setMetadata(["cordial:emailHash": emailHash])
```

```kotlin Kotlin
import io.radar.sdk.Radar
import org.json.JSONObject

Radar.setMetadata(JSONObject().put("cordial:emailHash", emailHash))
```

</CodeGroup>

The metadata key must match the setting exactly, including case. `Radar.setMetadata()` replaces the whole metadata object, so update it when the user logs out or changes.

## Test the integration

Set the identifier of an existing Cordial contact, move that user into a geofence with the [Simulator](https://dashboard.radar.com/geofencing/simulate), then click **View** on the new event on the **Events** page. Its **Logs** section shows a request to `/api/createContactactivities` with a `2xx` response, and the Cordial contact shows the `entered_geofence` activity and the `radar_geofence_tags` attribute. If not, see [Troubleshoot delivery](/integrations/integrations#troubleshoot-delivery).

## Limitations

Both environments share one async API endpoint and one secondary key setting.
