Prefer to create and manage geofences in your own dashboard? This tutorial shows you how to embed a Radar Map in your application and build a custom geofence creation interface. Geofences created through your dashboard will automatically appear in Radar's dashboard as well.

## What you'll build

You'll create a geofence creation tool that allows users to:

- Draw polygons and circles directly on an embedded Radar Map
- Fill out a form with geofence details (external ID, description, tag)
- Create geofences programmatically using Radar's API

## Features used

- [Radar Maps](https://docs.radar.com/maps/maps)
- [Create Geofence API](https://docs.radar.com/geofencing/geofences#api)
- Polygon drawing tool of your choice
- Circle drawing tool of your choice

## Getting started

If you haven't already, sign up for Radar to get your API key. Then add the Radar SDK to your application.

```
npm install radar-sdk-js @radarlabs/plugin-maps maplibre-gl
```

You'll also need to choose and install polygon and circle drawing libraries that are compatible with Radar Maps and MapLibre.

## Initialize the map

First, import the necessary libraries, register the maps plugin, and initialize Radar.

```javascript
import React from 'react';
import Radar from 'radar-sdk-js';
import { createMapsPlugin } from '@radarlabs/plugin-maps';
import '@radarlabs/plugin-maps/dist/radar-maps.css';

Radar.registerPlugin(createMapsPlugin());

componentDidMount() {
  // initialize with your publishable key
  Radar.initialize('prj_test_pk_...');

  // create map instance
  this.mapInstance = Radar.ui.map({
    container: 'map',
    center: [-73.9911, 40.7342], // NYC
    zoom: 14,
  });

  this.mapInstance.on('load', () => {
    this.initializeDrawTools();
  });
}
```

### Implement circle drawing

Create circles by calculating points around a center. When the user clicks to set the center, track mouse movement to calculate the radius, then generate a circle polygon.

## Create geofences via API

The geofence shape is a key part of creating the geofence; however, before calling the API, you must pass a geofence description, external ID, and tag as well.

To make sure users successfully pass these values, we recommend adding a form in this interface. This must collect three fields:

- External ID: A unique identifier for the geofence in your system
- Description: A description of the geofence
- Tag: A tag for organizing geofences

```javascript
// Store form data in component state
this.state = {
  formData: {
    name: '',        // External ID
    description: '', // Description
    tag: ''         // Tag
  },
  isSubmitting: false
};

// Handle form input changes
handleFormChange = (e) => {
  const { name, value } = e.target;
  this.setState(prevState => ({
    formData: {
      ...prevState.formData,
      [name]: value
    }
  }));
}
```

When the user submits the form, you'll pass these values to the API, as well as the geometry from the drawn geofence. Detect whether the geofence is a circle or polygon, and format the coordinates accordingly.

```javascript
handleFormSubmit = async (e) => {
  e.preventDefault();
  
  const { formData } = this.state;
  const { geofenceData } = this.props;
  
  // Validate that geofence data exists
  if (!geofenceData || !geofenceData.features || geofenceData.features.length === 0) {
    alert('No geofence data found');
    return;
  }

  // Get the drawn feature from your drawing tool
  const feature = geofenceData.features[0];
  const geometry = feature.geometry;
  
  // Prepare API payload
  let apiPayload = {
    description: formData.description,
  };

  // Detect circle vs polygon
  if (geometry.type === 'Polygon') {
    const coordinates = geometry.coordinates[0];
    
    // Detect if this is a circle (typically 64+ points in a regular pattern)
    const isCircle = coordinates.length >= 64;
    
    if (isCircle) {
      // Calculate center and radius for circle
      const center = this.calculatePolygonCenter(coordinates);
      const radius = this.calculateAverageRadius(center, coordinates);
      
      apiPayload.type = 'circle';
      apiPayload.coordinates = [center[0], center[1]];
      apiPayload.radius = Math.round(radius);
    } else {
      // Regular polygon
      apiPayload.type = 'polygon';
      apiPayload.coordinates = coordinates.map(coord => [coord[0], coord[1]]);
    }
  }

  try {
    this.setState({ isSubmitting: true });
    
    const tag = formData.tag || 'default';
    const externalId = formData.name;
    
    const response = await fetch(`https://api.radar.io/v1/geofences/${tag}/${externalId}`, {
      method: 'PUT',
      headers: {
        'Authorization': 'prj_test_sk_...', // Your secret key
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(apiPayload)
    });

    if (response.ok) {
      const result = await response.json();
      console.log('Geofence created successfully:', result);
      // Handle success - navigate away or show success message
    } else {
      const error = await response.json();
      console.error('Error creating geofence:', error);
      alert(`Error creating geofence: ${error.message || 'Unknown error'}`);
    }
  } catch (error) {
    console.error('Network error:', error);
    alert('Network error occurred. Please try again.');
  } finally {
    this.setState({ isSubmitting: false });
  }
}

// Helper function to calculate polygon center
calculatePolygonCenter = (coordinates) => {
  let totalLng = 0;
  let totalLat = 0;
  const validCoords = coordinates.slice(0, -1); // Exclude last coord (same as first)
  
  validCoords.forEach(coord => {
    totalLng += coord[0];
    totalLat += coord[1];
  });
  
  return [
    totalLng / validCoords.length,
    totalLat / validCoords.length
  ];
}

// Helper function to calculate average radius
calculateAverageRadius = (center, coordinates) => {
  const validCoords = coordinates.slice(0, -1);
  let totalDistance = 0;
  
  validCoords.forEach(coord => {
    // Use your geospatial library to calculate distance
    const distance = calculateDistance(
      [center[0], center[1]],
      [coord[0], coord[1]],
      { units: 'meters' }
    );
    totalDistance += distance;
  });
  
  return totalDistance / validCoords.length;
}
```

The API will return the created geofence object on success. The geofence will now appear in both your dashboard and Radar's dashboard.
