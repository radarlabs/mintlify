Every Radar project has two environments, Test and Live. Each environment has its own data and its own pair of API keys, so a project has four keys in total.

| Key | Prefix | Where to use it |
| --- | --- | --- |
| Test publishable | `prj_test_pk_` | Client code (mobile SDKs, web SDK) in development and staging builds. |
| Live publishable | `prj_live_pk_` | Client code in production builds. |
| Test secret | `prj_test_sk_` | Your backend only, against Test data. |
| Live secret | `prj_live_sk_` | Your backend only, against Live data. |

Find your keys on the [Settings](https://dashboard.radar.com/settings) page of the Radar dashboard, under **API keys**. Your account needs the Admin or Owner role to see them.

- **Publishable keys**: Safe to ship in client code. They can call only the API endpoints marked `Publishable` in the [API reference](/api/fundamentals).
- **Secret keys**: Can read and write project data. Keep them on your backend, load them from a secret store or environment variable, and never put one in a mobile app, a web page, or a source repository.
- **Environments**: Build and test with Test keys. Switch to Live keys only in production builds and on production backends. A user, geofence, or event created with a Test key doesn't appear in Live.

To call the API from your backend, send the secret key in the `Authorization` header:

```bash
curl "https://api.radar.io/v1/users" \
  -H "Authorization: prj_test_sk_..."
```
