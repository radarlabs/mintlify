---
title: "Address Enrichment"
description: "Radar's address enrichment returns what is known about the location at an address: whether it's residential, the type of dwelling, and the places there."
---

<Note>
  Address enrichment is available on request. Contact us at [radar.com/support](https://radar.com/support) if you would like it enabled for your project.
</Note>

## Quickstart

First, [sign up](https://radar.com/signup) for Radar and get an API key.

Then, [autocomplete](/maps/search#address-autocomplete) an address within a session and report the result the user chooses. With enrichment enabled for your project, that selection returns the enriched address.

See the autocomplete select API reference [here](/api#autocomplete-select).
