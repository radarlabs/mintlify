---
title: "Address Enrichment"
---

Use Radar's address enrichment to learn what is at an address: how the location is used, the type of dwelling, and the places on its grounds.

<Note>
  Address enrichment is available on request. Contact us at [radar.com/support](https://radar.com/support) if you would like it enabled for your project.
</Note>

## Quickstart

First, [sign up](https://radar.com/signup) for Radar and get an API key.

Then, [autocomplete](/maps/search#address-autocomplete) an address within a session and report the result the user chooses, either [directly](/api) or [using the SDK](/sdk/sdk). With enrichment enabled for your project, that selection returns the enriched address.

Use cases for address enrichment include distinguishing residential from commercial deliveries, pricing by dwelling type, and identifying the places on an address's grounds.

See the autocomplete select API reference [here](/api#autocomplete-select).
