The Radar Maps Migration SDK converts a web page built on the Google Maps JavaScript API to Radar Maps by replacing the script import tag. It doesn't cover Google web services that you call over HTTP. To port those, see [Google Maps Platform web services](#google-maps-platform-web-services). For other map libraries, see [Migrate to Radar Maps](/maps/overview#migrate-to-radar-maps).

## How it works

The Google Maps import on your page takes one of two forms. This is a direct `src` import:

```html
<script
  async
  src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&loading=async&callback=initMap"
>
</script>
```

This is a dynamic library import:

```html
<script>
  (g=>{var h,a,k,p="The Google Maps JavaScript API",c="google",l="importLibrary",q="__ib__",m=document,b=window;b=b[c]||(b[c]={});var d=b.maps||(b.maps={}),r=new Set,e=new URLSearchParams,u=()=>h||(h=new Promise(async(f,n)=>{await (a=m.createElement("script"));e.set("libraries",[...r]+"");for(k in g)e.set(k.replace(/[A-Z](/g,t=>"_"+t[0].toLowerCase()),g[k]);e.set("callback",c+".maps."+q);a.src=`https://maps.${c}apis.com/maps/api/js?`+e;d[q]=f;a.onerror=()=>h=n(Error(p+" could not load."));a.nonce=m.querySelector("script[nonce]")?.nonce||"";m.head.append(a)}));d[l]?console.warn(p+" only loads once. Ignoring:",g):d[l]=(f,...n)=>r.add(f)&&u().then(()=>d[l](f,...n))})({
    key: "YOUR_API_KEY",
    v: "weekly",
    // Use the 'v' parameter to indicate the version to use (weekly, beta, alpha, etc.).
    // Add other bootstrap parameters as needed, using camel case.
  });
</script>
```

For either import, replace these lines with the Radar Migration SDK script:

```html
<script src="https://js.radar.com/v1/radar-migration-sdk.js?key=prj_live_pk_..."></script>
```

Radar then serves the calls your page makes to the Google Maps JavaScript API. Test each map interaction your page uses after the change.

To set a callback or a Radar map style, add the query parameters in [Configuration](#configuration).

## Configuration

#### Definition

`src` `https://js.radar.com/v1/radar-migration-sdk.js`

### Query parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | string | None | Required. Your Radar publishable key. |
| `style` | string | `radar-default-v1` | The map style: `radar-default-v1`, `radar-light-v1`, `radar-dark-v1`, or a [custom style](/maps/maps#custom-styles) ID. See [Styles](/maps/maps#styles). |
| `callback` | string | None | The name of a maps callback function to call after the library is imported. |

## Google Maps Platform web services

Google web services called from your backend or app (geocoding, places, routes) are separate HTTP APIs, and the Migration SDK doesn't serve them. Port each call to the Radar endpoint that does the same job:

| Google Maps Platform | Radar |
| --- | --- |
| Dynamic Maps | [Display maps](/maps/maps) |
| Static Maps | [Static maps](/api/maps#static-maps) |
| Geocoding API | [Forward geocode](/api/geocoding#forward-geocode) |
| Reverse Geocoding API | [Reverse geocode](/api/geocoding#reverse-geocode) |
| Autocomplete API | [Autocomplete](/api/search#autocomplete) |
| Place Autocomplete UI | [Autocomplete component](/maps/addresses#add-the-autocomplete-component) |
| Address Validation API | [Validate an address](/api/geocoding#validate-an-address) |
| Nearby Search API | [Search places](/api/search#search-places) |
| Distance Matrix API | [Matrix](/api/routing#matrix) |
| Directions API | [Directions](/api/routing#directions) |
| Snap to Roads API | [Route match](/api/routing#route-match) |
| Speed Limits API | [Route match](/api/routing#route-match), with `speedLimit` in the `roadAttributes` parameter |
| Compute Routes API | [Matrix](/api/routing#matrix), [Directions](/api/routing#directions), or [Optimize route](/api/routing#optimize-route) |

Request parameters and response shapes differ between the two platforms, so each ported call needs its own request mapping and response parsing. Radar also offers [IP geocoding](/api/geocoding#ip-geocode), which has no direct Google Maps Platform equivalent in this table.
