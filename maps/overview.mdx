Radar Maps gives you base maps, geocoding, address autocomplete and validation, search, and routing behind one publishable key. By the end of this page you have made one geocoding request and rendered one map.

## Quickstart

<Steps>
  <Step title="Get a publishable key">
    Copy your Test publishable key (`prj_test_pk_...`) from the dashboard. See [Choose the right API key](/fundamentals/authentication-and-access#choose-the-right-api-key). Never put a secret key in client code. The web SDK refuses to initialize with one.
  </Step>
  <Step title="Make a request">
    Forward geocode an address. Pass the publishable key in the `Authorization` header.

    ```bash
    curl "https://api.radar.io/v1/geocode/forward?query=20+jay+st+brooklyn+ny" \
      -H "Authorization: prj_test_pk_..."
    ```

    A successful response has `meta.code` of `200` and an `addresses` array. Each address carries coordinates, structured fields, a `formattedAddress`, and a `confidence` value.

    ```json
    {
      "meta": {
        "code": 200
      },
      "addresses": [
        {
          "latitude": 40.7041,
          "longitude": -73.9867,
          "countryCode": "US",
          "stateCode": "NY",
          "city": "Brooklyn",
          "postalCode": "11201",
          "number": "20",
          "street": "Jay St",
          "layer": "address",
          "confidence": "exact",
          "formattedAddress": "20 Jay St, Brooklyn, New York, NY 11201 USA"
        }
      ]
    }
    ```

    If you get `401`, the key is missing or wrong. See [Authentication, errors, and rate limits](/api/fundamentals).
  </Step>
  <Step title="Display a map">
    Save this page as an HTML file, replace the key, and open it in a browser. It renders a Radar map centered on the address you geocoded, adds one marker, and shows a message if the map fails to load.

    ```html JavaScript
    <!DOCTYPE html>
    <html lang="en">
      <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <link href="https://js.radar.com/maps/v1.2.0/radar-maps.css" rel="stylesheet">
        <script src="https://js.radar.com/v5.3.0/radar.min.js"></script>
        <script src="https://js.radar.com/maps/v1.2.0/radar-maps.min.js"></script>
      </head>

      <body>
        <p id="map-status" role="status">Loading map...</p>
        <div id="map" style="width: 100%; height: 500px;"></div>

        <script>
          const statusEl = document.getElementById('map-status');
          let loaded = false;

          try {
            Radar.initialize('prj_test_pk_...');

            const map = Radar.ui.map({
              container: 'map',
              style: 'radar-default-v1',
              center: [-73.9867, 40.7041], // [longitude, latitude]
              zoom: 14,
            });

            map.on('load', () => {
              loaded = true;
              statusEl.hidden = true;

              Radar.ui.marker({ popup: { text: '20 Jay St' } })
                .setLngLat([-73.9867, 40.7041])
                .addTo(map);
            });

            map.on('error', (event) => {
              console.error('Map error', event.error);
              if (!loaded) {
                statusEl.textContent = 'The map could not load. Refresh the page to try again.';
              }
            });
          } catch (err) {
            // Thrown when the key is missing or is a secret key, or when the plugin did not load.
            console.error(err);
            statusEl.textContent = 'The map could not load.';
          }
        </script>
      </body>
    </html>
    ```

    You see a street map of Brooklyn with one marker, zoom buttons, and the Radar logo. Select the marker to open its popup. If the page is blank, check that the container has a width and a height and that the stylesheet loaded. For React, iOS, Android, and React Native, see [Display maps](/maps/maps).
  </Step>
</Steps>

## What Maps includes

| Capability | What it does | Guide | Reference |
| --- | --- | --- | --- |
| Map display | Interactive vector maps on the web and in native apps, plus static map images. | [Display maps](/maps/maps) | [Maps API](/api/maps), [Web SDK](/sdk/web) |
| Address tools | Autocomplete as a user types, forward and reverse geocoding, IP geocoding, and address validation. | [Autocomplete, geocode, and validate addresses](/maps/addresses) | [Geocoding API](/api/geocoding), [Search API](/api/search) |
| Search | Find your own locations (geofences) or places near a point. | [Build store locators](/maps/store-locators) | [Search API](/api/search) |
| Routing | Distance and duration, matrices, directions, route matching, and route optimization. | [Build store locators](/maps/store-locators#show-route-distance-and-travel-time) | [Routing API](/api/routing) |

Radar map data comes from [OpenStreetMap](https://www.openstreetmap.org). The interactive map component is built on [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/), so MapLibre options, events, and plugins work with it.

## Migrate to Radar Maps

For a web page built on the Google Maps JavaScript API, replace the Google Maps script tag with the Radar [Migration SDK](/maps/migration-sdk) script tag, and existing `google.maps` calls are served by Radar. The Migration SDK is a compatibility layer, so test every map interaction, control, and overlay after the swap.

Google web services (geocoding, places, routes) aren't covered by the Migration SDK. Port each call to the matching operation in the [Geocoding API](/api/geocoding), [Search API](/api/search), or [Routing API](/api/routing).

There's no migration SDK for Mapbox, MapLibre, or Leaflet. Point your existing map at a Radar style URL, or move to the Radar web SDK. See [Compatibility](/maps/maps#compatibility).
